A web UI for your own JDownloader. Faster. Faster. More modern. Self-hosted. Phone-friendly. Private.

My Own JDownloader replaces the hosted MyJDownloader page with one small container on your side. A live UI, a direct line to your JDownloader, captchas and Click'n'Load that work on the phone too.

View on GitHub Clone and run
Features

Everything you do in JDownloader, without the detour.

Live downloads

Progress, speed graph and bandwidth history, drag and drop ordering, and a context menu for everything JDownloader can do with a package or link.

Linkgrabber

Filter by host and file type, see what is online, and send the good packages to the downloads in one click.

Several JDownloaders

Pick one device or look at all of them together. They can run anywhere: a NAS, a server, your PC. Nothing has to be installed next to them.

Captchas in the browser

Image captchas in the UI, reCAPTCHA, hCaptcha and Turnstile through the browser extension or the Android app, on the hoster's own page.

All settings on one page

Generated from what the device reports, so a newer JDownloader needs no update here. Accounts, hosters and extensions included.

Plugins and themes

Plugins add content such as movie posters and YouTube thumbnails to the package cards. Light and dark theme, and it works on small screens.

Browser extension

Manifest V3. Back in current Chrome.

Current Chromium browsers no longer run the old Manifest V2 MyJDownloader extension. This one is built on Manifest V3, so it works in Chrome, Edge, Brave and other Chromium browsers again.

Popup with your devices, speed graph and queue at a glance.
Click'n'Load takes over links from the websites you visit.
Captcha solving on the hoster's own page, with a countdown.
Self-update from your own server, no store needed.
Quick start

Two files, one command.
Fill in .env and go.

The ready-made image is pulled for you, nothing to build. You need Docker with Compose and a MyJDownloader account with at least one connected JDownloader. Set a UI password, and put the app behind HTTPS if it is reachable from outside your network.

Read the full guide on GitHub
shell 
$ mkdir my-own-jdownloader && cd my-own-jdownloader
$ curl -fLO https://raw.githubusercontent.com/bennyborn/my-own-jdownloader/master/compose.yaml
$ curl -fL https://raw.githubusercontent.com/bennyborn/my-own-jdownloader/master/.env.example -o .env
$ nano .env   # your MyJDownloader login + UI_PASSWORD
$ docker compose up -d
